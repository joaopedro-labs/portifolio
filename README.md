## 🚀 Como Publicar Gratuitamente no GitHub Pages

1. Crie um repositório público no seu GitHub (`joaopedro-labs`) chamado **`portfolio`** (ou **`joaopedro-labs.github.io`**).
2. No terminal, dentro desta pasta (`c:\Users\GEDAIA_028355\Documents\Projects\portfolio`), execute:
   ```bash
   git init
   git add .
   git commit -m "feat: portfólio profissional João Pedro Araujo"
   git branch -M main
   git remote add origin https://github.com/joaopedro-labs/portfolio.git
   git push -u origin main
   ```
3. No GitHub, acesse **Settings > Pages**, selecione a branch **`main`** e clique em **Save**.
4. Seu portfólio ficará online em:
   `https://joaopedro-labs.github.io/portfolio/`
